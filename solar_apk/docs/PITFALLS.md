# Подводные камни

## Способ A (Ollama на ПК, APK — клиент)
- **Сеть**: телефон и ПК должны быть в одной подсети; корпоративные/гостевые Wi-Fi часто включают client isolation — соединения нет. Решение: домашний роутер, режим AP на телефоне или Tailscale.
- **Брандмауэр Windows** молча блокирует 11434 — самое частое «почему не работает». Разрешите входящий TCP 11434 (Private network).
- **OLLAMA_HOST по умолчанию = 127.0.0.1** — без `0.0.0.0` внешние подключения отклоняются.
- **HTTP вместо HTTPS**: Android 9+ требует cleartext для `http://`; Kivy/P4A это разрешает по умолчанию, но если пишете нативный клиент — добавьте `usesCleartextTraffic=true` / network security config.
- **Энергия ПК**: простой/сон останавливает сервер — отключите сон при использовании.

## Способ B (llama.cpp в телефоне)
- **RAM**: правило — квант модели должен занимать ≤ (RAM − 4 ГБ). 8 ГБ → комфортно 3–4B Q4; 12–16 ГБ → 7–8B Q4; 7B Q5+ на 8 ГБ = вылеты OOM-killer.
- **Нагрев и троттлинг**: 3B генерит ~5–10 ток/с и греет корпус за 3–5 минут; длинные сессии → падение скорости в 2 раза. Снимите чехол, избегайте солнца, делайте паузы.
- **Батарея**: локальный инференс — самый прожорливый сценарий после камеры; 10 минут активного чата ≈ 5–10% заряда.
- **Размер APK**: llama.cpp нативные библиотеки добавляют ~15–30 МБ на ABI (arm64+v7a ≈ 40–60 МБ APK). Сама модель НЕ в APK: 2–5 ГБ GGUF хранятся отдельно; не кладите её в assets (APK раздуется и установка будет долгой).
- **Хранилище**: выделяйте 3+ ГБ свободного места; медленный eMMC/UFS старого телефона = долгие загрузки модели.
- **Контекст**: num_ctx 8k+ на телефоне резко увеличивает потребление RAM — держите 2–4k.
- **Сборка под Windows**: Buildozer на Windows НЕ работает (только Linux/WSL2); в WSL2 иногда ломается доступ к файлам между `/mnt/c` и ext4 — держите проект внутри home (`~/projects/solar_app`), иначе сборка падает на symlink/правах. Первая сборка Buildozer скачивает ~5–8 ГБ (SDK+NDK+компиляция wheels) и занимает 30–60 минут.
- **Cython/Kivy**: свежий Cython 3.x ломает старыеrecipe P4A — фиксируйте `cython==0.29.36`.
- **Подпись release**: debug-APK ставится легко; release нужно подписать keytool/apksigner и хранить keystore (потеряли — не обновляете приложение поверх).

## Безопасность
- Ollama на 0.0.0.0 открыт всей локальной сети — нормально дома, опасно в кафе. Не публикуйте порт в интернет; при необходимости — Basic Auth через reverse-proxy (Caddy/nginx) или SSH/Tailscale.
