# Чек-лист готовности

## Этап 0 — выбор пути
- [ ] Решено: A (Ollama на ПК) или B (оффлайн llama.cpp в телефоне)
- [ ] Телефон: Android ≥ 8.0 (API 24+), known RAM (для B: ≥ 8 ГБ)

## Этап 1 — сервер модели (способ A)
- [ ] Ollama установлен (`ollama --version`)
- [ ] `OLLAMA_HOST=0.0.0.0:11434` применён (сервис перезапущен)
- [ ] Модель скачана: `ollama list` содержит qwen2.5:3b (или вашу)
- [ ] `curl http://localhost:11434/api/tags` → JSON
- [ ] Брандмауэр: входящий TCP 11434 разрешён
- [ ] **С другого устройства в той же сети**: `curl http://IP_ПК:11434/api/tags` → JSON ✅

## Этап 2 — APK
### Вариант «взять готовый»
- [ ] Скачан APK из Releases (OllamaApp / ChatterUI)
- [ ] Установлен на телефон («неизвестные источники» разрешены)
- [ ] Имя бота задано: «Solar»
### Вариант «собрать самому» (Kivy/Buildozer)
- [ ] WSL2/Ubuntu: зависимости из BUILD.md установлены
- [ ] `python3 -m venv` создан, `pip install buildozer cython==0.29.36 kivy`
- [ ] В buildozer.spec: `title = Solar`, package/org заданы
- [ ] `buildozer android debug` завершился без ошибок
- [ ] `bin/Solar-*.apk` существует (>15 МБ)

## Этап 3 — подключение клиента
- [ ] Телефон и ПК в одной Wi-Fi сети
- [ ] В приложении указан `http://IP_ПК:11434` и имя модели
- [ ] Тестовый вопрос возвращает ответ бота «Solar»
- [ ] Ответ переживает сворачивание приложения (нет крашей)

## Этап 4 — способ B (если выбран)
- [ ] GGUF-модель ≤ (RAM − 4 ГБ), скачана на телефон
- [ ] Персона «Solar» создана (Name + System prompt)
- [ ] Первый ответ сгенерирован; скорость ≥ 3 ток/с устраивает
- [ ] Нагрев в норме (тест 10 минут), батарея не просела критично

## Этап 5 — финализация
- [ ] Release-APK подписан, keystore сохранён в надёжное место
- [ ] Документация (README этого проекта) обновлена вашим IP/моделью
- [ ] (Опц.) Tailscale настроен для доступа вне дома
